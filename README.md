# Автоскролл для YouTube, TikTok и Instagram

Расширение автоматически переходит к следующему видео после окончания текущего. Работает с YouTube Shorts, видеолентами TikTok и Instagram Reels.

## Установка из папки

1. Скачайте расширение. <img width="390" height="330" alt="image" src="https://github.com/user-attachments/assets/cc33fbad-d2d7-4220-82b3-50042a2a5d74" />

2. Откройте `chrome://extensions` и включите «Режим разработчика». <img width="1895" height="285" alt="image" src="https://github.com/user-attachments/assets/8151bb51-ad6f-4d9b-bcf5-9124e7ac346f" />
3. Распакуйте расширение.
4. Нажмите «Загрузить распакованное расширение» и выберите папку с распакованным расширением.<img width="482" height="227" alt="image" src="https://github.com/user-attachments/assets/14cd1cc7-cd7d-45c2-9955-3569fc59598d" />

5. Обновите открытые вкладки YouTube, TikTok и Instagram.
6. В меню расширения выберите нужные сети. Выбранная кнопка подсвечена серым. Общая кнопка включает автоскролл сразу во всех выбранных сетях.

По умолчанию выбраны только YouTube Shorts, чтобы обновление не меняло уже сохранённые привычки. Instagram и TikTok можно включать по отдельности или вместе. Выбор и общее включение сохраняются между перезапусками.

После обновления файлов откройте страницу расширений, нажмите круглую стрелку на его карточке и один раз перезагрузите уже открытые вкладки соответствующих соцсетей. Если переключатель серый, сеть выключена. На странице Reels или TikTok во время работы появляется небольшое сообщение о состоянии.

## Поддерживаемые страницы

- YouTube Shorts. YouTube-обработчик остался отдельно от Instagram и TikTok.
- Instagram Reels: лента `/reels/` и ролики `/reel/` в профиле. Обычные публикации, Stories и прямые эфиры не переключаются.
- TikTok: видеоленты «Рекомендации», «Подписки», «Друзья» и страница видео профиля. Фото, истории и прямые эфиры не переключаются.

Расшерение предназначено исключительно для удобства использования соц сетей.
