# Автоскролл для YouTube, TikTok и Instagram

Расширение автоматически переходит к следующему видео после окончания текущего. Работает с YouTube Shorts, видеолентами TikTok и Instagram Reels.

## Установка из папки

1. Откройте `chrome://extensions` и включите «Режим разработчика».
2. Нажмите «Загрузить распакованное расширение» и выберите папку с `manifest.json`.
3. Обновите открытые вкладки YouTube, TikTok и Instagram.
4. В меню расширения выберите нужные сети. Выбранная кнопка подсвечена серым. Общая кнопка включает автоскролл сразу во всех выбранных сетях.

По умолчанию выбраны только YouTube Shorts, чтобы обновление не меняло уже сохранённые привычки. Instagram и TikTok можно включать по отдельности или вместе. Выбор и общее включение сохраняются между перезапусками.

После обновления файлов откройте страницу расширений, нажмите круглую стрелку на его карточке и один раз перезагрузите уже открытые вкладки соответствующих соцсетей. Если переключатель серый, сеть выключена. На странице Reels или TikTok во время работы появляется небольшое сообщение о состоянии.

## Поддерживаемые страницы

- YouTube Shorts. YouTube-обработчик остался отдельно от Instagram и TikTok.
- Instagram Reels: лента `/reels/` и ролики `/reel/` в профиле. Обычные публикации, Stories и прямые эфиры не переключаются.
- TikTok: видеоленты «Рекомендации», «Подписки», «Друзья» и страница видео профиля. Фото, истории и прямые эфиры не переключаются.

На сайтах кнопки и внутренняя разметка меняются без уведомления; после таких изменений может понадобиться обновление расширения.

## Проверки

```sh
npm ci
npm test
npx playwright install chromium --no-shell
npm run test:browser
```

Логические тесты проверяют сохранение настроек, все восемь вариантов выбора соцсетей и переключение для каждого сайта. Браузерные тесты проверяют настоящие видеоэлементы, переходы по нескольким роликам, паузу, прокрутку ленты и постоянный размер панели на локальных тестовых страницах. Запросы тестовых страниц не отправляются Instagram или TikTok.

В Windows, если комплектный Chromium не запускается:

```powershell
$env:SCROL_TEST_CHANNEL = 'msedge'
npm run test:browser
```

Реальную Instagram-страницу проверяли отдельно на публичной ленте: её адрес `/reels/<id>/`, кнопка «К следующему видео Reels» и прокручиваемый контейнер распознаются расширением. Внешние сайты со временем меняют интерфейс; автоматические браузерные тесты используют локальные имитации, а не учётную запись пользователя.
